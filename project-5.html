1 · Overview

Project overview & problem statement

The problem

Raw stock prices in a table are hard to read. This app lets a user explore how a stock’s price has moved and performed through interactive charts.

Main goals

  • Explore stock price trends and performance interactively.
  • Keep the code modular so it is easy to maintain and extend.
  • Practise a real web-app structure and version control.

5 · Conclusion

Conclusion & business impact

Conclusion

The project is a clean base for stock exploration and shows how to structure a data app so it can grow.

Actionable takeaways

  • Interactive charts make trends easier to read than a table of prices.
  • A modular structure matters as much as the analysis itself.
  • The app explores data and does not give investment advice.
